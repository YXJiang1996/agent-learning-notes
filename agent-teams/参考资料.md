## 版本行为依据

<a id="e1"></a>
### E1 · Claude Code 2.1.198 文件与工具行为观察

- 类型：版本限定的运行观察，不是官方规范或源码事实。
- 条件：交互式 in-process 模式，启用 Agent Teams，default 权限，safe mode，单个命名队友；未进行并发竞争、依赖或故障注入验证。
- 文件结果：团队配置包含成员身份和后端信息；收件箱文件存在且采样内容为 `[]`；任务目录存在任务 JSON、`.lock`、`.highwatermark`。
- 数据结果：任务 JSON 包含 `id`、`subject`、`description`、`status`、`blocks`、`blockedBy`；成员信息包含 `name`、`agentId`、`agentType`、`model`、`backendType` 等字段。
- 工具结果：能区分 TaskCreate、TaskUpdate(owner)、Agent、SendMessage、TaskUpdate(completed)、TaskGet；向主会话发送的返回结果为排入下一轮。任务完成工具返回还提示查看 TaskList。
- 生命周期结果：退出后团队目录消失，任务目录及一个 pending 任务保留。某 completed 任务由 TaskGet 确认，但其文件未被采到，不能推导永久保留语义。
- 转录形式：主会话 JSONL 和会话子目录中的队友 JSONL 可记录工具调用与结果；这不是邮箱消费算法的证据。
- 限制：没有采到非空邮箱格式；`.highwatermark` 只确认存在，编号管理用途属于命名推断；锁的实际原语、消费确认、自动恢复未获得源码证明。
- 复核方式：在隔离目录中让一个队友读取无敏感信息的文件并回报，通过任务工具、匹配该会话的配置与转录核对，再比较退出前后目录。此处只保留产品条件和结果，不收录私人会话标识、绝对路径、模型服务配置或原始日志。
- 无独立公开原始数据链接。此项提供版本观察的证据范围，不能冒充官方承诺；正式依赖内部细节前应在目标版本复核。
