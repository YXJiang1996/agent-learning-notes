## 学习助手

[学习助手 Skill](skill/SKILL.md)适用于任意知识主题，用于拆解前置知识、制定计划、解释与按需测评，以及整理完整的知识文章。工程主题可结合产品、源码与论文，其他学科按内容选择方法。个人计划、作答和进度由会话或仓库外的本地目录管理。

将整个 `skill/` 目录以 `learning-coach` 为目录名放到所用 Agent 的技能目录，按宿主的 Skill 加载方式使用；没有 Skill 加载能力的工具可以直接读取 `SKILL.md`。Skill 不绑定特定连接器或模型。

示例请求：

> 使用 learning-coach，围绕 Agent 记忆机制制定学习计划，优先研究真实产品和开源实现。计划在对话中给出。

> 将这些机制整理成知识文章，分别归入通用知识和具体产品实现，参考链接集中写入主题的参考资料文档。

## 组织约定

- 根目录按知识主题建立文件夹，有内容后再创建。
- 每个主题以一篇通用文章、每个产品或项目一篇实现分析、一个参考资料文档为主。
- 中文文件名明确写出主题、对象和文章用途；不按每个小机制拆文件，不嵌套多层分类。
- 正文完整解释必要概念、细节、机制与边界；浅目录不意味着删减内容。参考资料提供依据，不能替代正文。
- 正文呈现知识结论，不包含个人学习记录、课程进度、问答过程或待办清单。
- 实现事实注明证据与版本；推断和设计建议明确标识。参考资料单独归档，正文使用资料编号引用。
