# Agent 学习笔记

围绕 Agent Teams、记忆与沙箱机制，结合业界产品、开源实现、理论基础和论文，记录源码分析、方案对比、动手实验与学习进度。

## 学习目标

不仅理解概念，还要能够回答：真实系统如何实现、为什么这样设计、有什么限制，以及自己需要实现时应如何选择方案并验证效果。

## 重点主题

| 主题 | 核心问题 |
| --- | --- |
| 多 Agent 协作（Agent Teams） | 任务拆解、角色分配、消息通信、共享状态、结果汇总、失败重试与成本控制 |
| 记忆机制 | 信息选择、写入时机、存储与检索、过期与冲突处理、效果评估 |
| 沙箱机制 | 资源隔离、权限控制、环境生命周期、文件与网络访问、执行结果回收 |

## 学习方法

提出工程问题 → 补充必要理论 → 研究产品与源码 → 比较方案 → 完成最小实现 → 验证理解 → 沉淀设计结论。

每个主题优先深入一个主项目，再按具体问题选择对照项目。论文阅读与工程问题关联，避免无边界扩展学习范围。

## 学习助手 Skill

第一版已提供：[Agent 系统学习助手](skills/learning-coach/SKILL.md)。支持研究规划、产品与源码分析、论文关联、实验指导、简短测评，以及基于证据的学习进度更新。

Skill 文件和个人学习记录分别保存。安装后，每次指定学习仓库，助手会从保存的计划与记录接续工作。实际研究仍需要宿主提供文件读写、源码检索或联网能力；只有提示词的环境不能自动同步 GitHub。

### 安装与使用

将 `skills/learning-coach/` 整个目录复制或链接到所用 Agent 的技能目录。Codex 可使用个人目录 `~/.agents/skills/learning-coach`，也可放入项目的 `.agents/skills/learning-coach`。其他 Agent 按其技能加载方式接入；不支持自动发现 Skill 时，可明确要求读取 `SKILL.md` 及所需引用文件。

例如：

> 使用 $learning-coach，把当前仓库作为学习仓库。我想研究 Agent 的记忆机制，请先了解我的基础，再拆成工程问题并制定学习计划。

> 使用 $learning-coach，读取已有计划和记录，继续今天的源码学习。

> 使用 $learning-coach，围绕本轮掌握标准出几道测试题，等我作答后再评价和更新进度。

首次真正开始学习时，助手会按需创建 `learning-hub.json` 标记及相应档案，不预填学习完成记录。进度脚本仅需 Python 3.9 或以上版本，使用方式见 Skill。脚本检查格式、引用、依赖及证据字段，不替代人工判断证据是否充分。

## 记录规范

- 描述、笔记、方案比较、学习计划与测评反馈均使用中文；代码标识符和项目原名保留原文。
- 区分官方说明、源码事实、实验观察、论文结论与个人推测。
- 源码分析记录仓库、提交版本、文件路径和关键符号；产品文档记录访问日期；论文记录版本和相关章节。
- 闭源产品的内部实现缺少证据时明确标为未知，不根据外部表现断言其内部机制。
- 不同方案在相同场景和约束下比较，并标明未验证的部分。
- 参考资料保留来源和阅读位置，附件仅收录可合法分享的内容。

## 掌握评估

分别记录概念理解、源码追踪、设计判断、独立实现和效果验证。完成阅读不自动等于掌握，Agent 生成代码不自动算作独立实现。

通过简短测试、源码追踪、故障推演、实现任务和迁移设计收集证据，记录提示或辅助程度，再调整学习计划。
